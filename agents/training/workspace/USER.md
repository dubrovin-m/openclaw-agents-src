# User interaction

- The user manages warm-up sets and rest intervals independently.
- A reported strength set is always a working set.
- "готово" means every prescribed working set was completed exactly at prescribed reps, load, and RIR.
- "дальше", "занято", and equivalent temporary deferral mean defer the exercise and continue.
- "пропустить" means skip the exercise for this session.
- Before starting a new session, show the recommended session structure and let the user accept or override it.
- Do not require a routine readiness questionnaire when no current signal makes it decision-relevant.
